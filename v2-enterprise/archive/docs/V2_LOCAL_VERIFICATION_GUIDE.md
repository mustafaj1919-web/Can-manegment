# دليل التحقق والتشغيل المحلي لـ Windows (V2 Local Verification Guide)

يرجى اتباع الخطوات التالية خطوة بخطوة للتحقق من بناء وتشغيل نظام معرض السيارات v2.0 Enterprise محلياً على نظام Windows.

---

## المتطلبات الأساسية (Prerequisites)

1. **تثبيت .NET 8.0 SDK**:
   * قم بتحميل وتثبيت الحزمة الرسمية من موقع مايكروسوفت: [Download .NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. **تثبيت Docker Desktop**:
   * قم بتحميل وتثبيت Docker Desktop لنظام Windows (مع تفعيل محرك WSL 2) من الموقع الرسمي لـ Docker.

---

## خطوات التحقق والتشغيل خطوة بخطوة

يرجى فتح واجهة الأوامر (PowerShell أو Command Prompt) كمسؤول، ثم الانتقال إلى مجلد المشروع الفرعي `v2-enterprise`:
```powershell
cd d:\System\car_showroom_management\v2-enterprise
```

ثم قم بتشغيل الأوامر التالية بالترتيب:

### الخطوة الأولى: التحقق من تثبيت الـ SDK
تأكد من أن نظام التشغيل يتعرف على أداة dotnet وتظهر نسخة الإصدار 8.0:
```powershell
dotnet --version
```

### الخطوة الثانية: استعادة التبعيات وحزم الـ NuGet
قم بتحميل واستعادة كافة الحزم البرمجية المطلوبة للحل:
```powershell
dotnet restore
```

### الخطوة الثالثة: بناء الحل (Build Solution)
قم ببناء كامل المشاريع في وضع التطوير (Debug) للتأكد من عدم وجود أخطاء في الـ Compilation:
```powershell
dotnet build
```

### الخطوة الرابعة: تشغيل اختبارات الوحدة (Run Unit Tests)
قم بتشغيل كافة الاختبارات للتأكد من مطابقة شروط الأمان المحاسبي والقيود وعزل الفروع:
```powershell
dotnet test
```
*(يتوقع نجاح 10 اختبارات وحدة تشمل اختبارات القيود التاريخية المكتوبة مسبقاً، واختبارات العملاء والمخزون المضافة حديثاً).*

### الخطوة الخامسة: التحقق من ملف Docker Compose
قم بالتحقق من صحة صياغة وتكوينات ملف تشغيل الحاويات:
```powershell
docker compose config
```

### الخطوة السادسة: بناء وتشغيل البيئة بالكامل
قم ببناء حاوية الـ API وتشغيل قاعدة البيانات PostgreSQL والذاكرة المؤقتة Redis معاً:
```powershell
docker compose up --build
```

### الخطوة السابعة: التحقق من نجاح التشغيل
بمجرد اكتمال التشغيل وظهور السجلات في الواجهة:
* **فحص الصحة (Health Check)**: افتح المتصفح وتأكد من رجوع الحالة الصحية للنظام عبر الرابط: `http://localhost:8080/healthz`.
* **مستندات Swagger API**: قم بمطابقة واختبار واجهات الـ API للعملاء والمخزون والمحاسبة عبر الرابط: `http://localhost:8080/swagger/index.html`.
* **تخزين المستندات المحمي**: قم باختبار رفع مستند عميل والتحقق من حفظ الملف في مجلد `v2-enterprise/storage/private/customers` وتجربة تحميله عبر مسار الـ API المحمي بالصلاحيات والفرع.
