# تقرير الجاهزية للفحص الميداني النهائي وقبول المستخدم (UAT Release Report)

تمت المراجعة الشاملة لتطبيق الموبايل والواجهات البرمجية الخاصة به، والتأكد من جاهزيته الكاملة للاختبار والتشغيل الميداني على أجهزة Android و iOS.

---

## 1. إعدادات خادم الاتصال (Production API Configuration)

تم ربط تطبيق الموبايل ديناميكياً بخادم الـ API عبر مسار السيرفر الإنتاجي:
`EXPO_PUBLIC_API_URL=http://100.75.153.105/api`

> [!IMPORTANT]
> **ملاحظة أمنية للإنتاج:**
> قبل رفع التطبيق للمتاجر الرسمية (Google Play / App Store)، يجب حجز دومين رسمي آمن وتفعيل شهادة **SSL (HTTPS)** بدلاً من الـ IP المباشر و الـ HTTP.

---

## 2. أمان خصوصية البيانات (Public Data Security)

تم التحقق من عزل البيانات العامة للسيارات عن الهيكل المالي للمعرض، فالواجهات العامة **لا تكشف إطلاقاً**:
* أسعار الشراء الفعلي للسيارات.
* الهوامش الربحية المستهدفة.
* القيود والسجلات اليومية للمحاسبة.
* بيانات وهوية الموردين.

---

## 3. بوابة الزبائن والتحقق (Customer Authentication)

تعتمد بوابة الزبائن على آلية دخول مبسطة وآمنة:
* **اسم المستخدم**: رقم الهاتف المسجل في عقد البيع.
* **كلمة المرور**: رقم الهوية الوطنية أو جواز السفر (`IdNumber`) المسجل بالعقد.
* **التحقق**: يتم توليد رمز JWT آمن وصالح لمدة 24 ساعة للوصول لخدمات كشف الأقساط والمدفوعات.

---

## 4. تجربة المستخدم والتجاوب (UX & RTL Arabic)

* يدعم التطبيق التوجيه العربي الكامل **RTL (من اليمين لليسار)**.
* تم تفعيل شاشات المعاينة الفرعية ورسائل التنبيه التفاعلية عند انقطاع الإنترنت أو بطء الاستجابة.
* شاشات `ListEmptyComponent` مهيأة لعرض رسائل توضيحية ممتازة في حال عدم وجود سيارات في المفضلة أو جدول الأقساط.

---

## 5. أوامر التشغيل والبناء البرمجي (Build Commands)

### تشغيل خادم التطوير للتجربة الحية:
```bash
cd mobile-app
npm start
```

### بناء نسخة التجربة السريعة (Preview APK):
```bash
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```

### بناء نسخة الإنتاج المحلية للأندرويد:
```bash
npx expo run:android --variant release
```
