# تطبيق موبايل "معرض الأصدقاء للسيارات" (Al-Asdeqa Auto Mobile App)

تطبيق هاتف محمول متكامل (Android & iOS) مبني باستخدام **React Native Expo** و **TypeScript** وموجّه بالكامل للزبائن ومرتبط بالـ ERP الأساسي.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Framework**: React Native Expo (Blank TypeScript)
* **Styling**: Vanilla React Native Stylesheets (مع لوحة ألوان فخمة متناسقة)
* **Icons**: Lucide React Native
* **Storage**: Async Storage (لتخزين جلسة دخول الزبون والمفضلات محلياً)

---

## 📁 الهيكل البرمجي للمجلدات (Folder Structure)
```text
mobile-app/
  ├── App.tsx                     # نقطة دخول التطبيق والمتحكم العام بالمسارات والتنقل
  ├── app.json                    # إعدادات مشروع Expo
  ├── src/
  │   ├── components/
  │   │   ├── ui/                 # عناصر واجهة المستخدم المشتركة (Button, Input, Badge)
  │   │   └── vehicle/            # مكونات عرض بطاقة السيارة (VehicleCard)
  │   ├── screens/                # شاشات التطبيق الأساسية (العامة وبوابة الزبون)
  │   ├── services/               # خدمات جلب البيانات والربط بالـ API (apiClient, authService...)
  │   ├── store/                  # مخازن الحالات البسيطة (authStore, favoriteStore)
  │   ├── theme/                  # لوحة الألوان المشتركة (colors)
  │   ├── types/                  # واجهات TypeScript للنماذج والبيانات
  │   └── utils/                  # وظائف مساعدة عامة (formatCurrency, formatDate)
```

## 🚀 طريقة التشغيل والتجربة (Running the App)

### 1. تثبيت الاعتمادات (Installation)
ادخل إلى مجلد التطبيق وقم بتثبيت الحزم البرمجية:
```bash
cd mobile-app
npm install
```

### 2. إعدادات الاتصال بالـ API
بشكل افتراضي، يتصل التطبيق بعنوان السيرفر الإنتاجي مباشرة:
`http://100.75.153.105/api`
إذا كنت تريد تغيير المسار أو التجربة محلياً، يمكنك تعديل الثابت `BASE_URL` في الملف التالي:
`src/services/apiClient.ts`

### 3. تشغيل خادم التطوير (Start Dev Server)
شغّل الأمر التالي لبدء خادم تطوير Expo:
```bash
npm start
```

### 4. تجربة التطبيق حياً على هاتفك المحمول 📱
1. قم بتحميل تطبيق **Expo Go** مجاناً من متجر التطبيقات (App Store للآيفون أو Google Play للأندرويد).
2. افتح كاميرا هاتفك وامسح رمز الاستجابة السريعة **(QR Code)** الذي يظهر لك في مبسط الأوامر (Terminal).
3. سيفتح التطبيق ويعمل مباشرة على هاتفك بكل سلاسة وحركات تفاعلية!
