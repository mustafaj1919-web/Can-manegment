# Hero video

Place your homepage hero video here with these exact filenames:

- `hero.mp4` (required — main video, H.264, ideally under ~15MB)
- `hero.webm` (optional — better compression/quality, used first if present)
- `hero-poster.jpg` (optional — a single frame shown while the video loads)

Recommended: 1920x1080 or 1280x720, 10-20 seconds, no audio needed (it plays
muted), landscape orientation, subject centered enough to still read well on
mobile portrait crops.

If no video is present, the homepage automatically falls back to the
animated vehicle scene — nothing breaks either way.
